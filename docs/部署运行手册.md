# 部署运行手册

更新时间：2026-04-22

## 1. 运行前提

- Node.js / npm 可用
- Python 3.10+ 可用
- MySQL、Redis 可用
- 可选：MinIO、EVM 测试网配置

## 2. 后端启动

```bash
cd backend
npm install
npm run build
npm run start:dev
```

必配文件：`backend/.env`（可从 `.env.example` 复制）。

## 3. AI 服务启动

```bash
cd ai
pip install -r requirements.txt
uvicorn service.app:app --host 0.0.0.0 --port 9001
```

## 4. 小程序联调配置

文件：`services/config.js`

建议：

- 开发：`CURRENT_ENV='dev'`、可保留 `MOCK_FALLBACK=true`
- 真机调试：`DEFAULT_LAN_BASE_URL` 使用电脑局域网地址（例如 `http://192.168.1.103:8080`），不要使用 `127.0.0.1` 或 `localhost`
- 测试/预发：建议 `MOCK_FALLBACK=false`
- 生产：`MOCK_FALLBACK=false`

## 5. 关键环境变量

后端重点：

- 数据与认证：`DATABASE_URL`,`REDIS_*`,`JWT_*`
- AI：`DISEASE_AI_*`,`AI_SERVICE_URL`,`FRUIT_PERCEPTION_PATH`
- 天气：`WEATHER_PROVIDER`,`WEATHER_API_KEY`,`WEATHER_DEFAULT_LOCATION_ID`
- LLM：`OPENAI_*` 或 `DEEPSEEK_*` 或 `LLM_*`
- 溯源锚定：`TRACE_*`,`EVM_*`
- 小程序码直达：`WECHAT_MP_*`

微信扫一扫直达小程序建议配置：

- `WECHAT_MP_CODE_ENABLED=true`
- `WECHAT_MP_APP_ID=<小程序 appid>`
- `WECHAT_MP_APP_SECRET=<小程序 secret>`
- `WECHAT_MP_CODE_PAGE=pages/trace-view/index`
- `WECHAT_MP_ENV_VERSION=release`（联调可用 `trial` / `develop`）

## 6. 运行检查清单

1. `GET /docs` 可访问（开发环境）。  
2. `GET /api/weather/current` 正常返回。  
3. `POST /ai/disease/predict` 可返回结构化字段。  
4. `POST /ai/fruit/grade` 可返回分级和价格区间。  
5. `GET /api/risk/:batchId` 可返回等级和建议。  
6. `GET /api/trace/:code/verify` 可返回 `verified`。
7. `POST /api/products/:id/qrcode` 返回 `qrcodeType`，并在微信“扫一扫”可直达小程序溯源页。

## 7. 常见问题

- 病害或分级总是回退：检查 AI 服务是否可达、路径是否一致。  
- 天气请求异常：检查 provider 配置和默认位置格式。  
- trace 锚定失败：检查 `TRACE_ANCHOR_ENABLED` 和 `EVM_*` 配置。
